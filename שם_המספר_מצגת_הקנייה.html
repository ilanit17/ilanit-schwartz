📐 שלושת השלבים

כדי להגות כהלכה את שם המספר, עוברים שלושה שלבים:

1

לאיזה שם עצם המספר מכוון?

בודקים: את מה סופרים? מזהים את שם העצם שהמספר מלווה.

2

קובעים את מין שם העצם

נוטים את שם העצם ליחיד ומצמידים שם תואר. לדוגמה: קיר → קיר גבוה → זכר.

3

נעזרים בטבלה ובוחרים את הצורה המתאימה

מהגים את המספר בזכר או בנקבה, נפרד או נסמך – לפי הצורך.

דוגמה: כיצד נהגה את המספר בצירוף "3 קירות"?
קירות → קיר → קיר גבוה → זכר → שלושה קירות ✓

💡 עיקרון חילופי המינים (1–10):

שם עצם זכר → מספר מסתיים ב-ה (שלושה ילדים)  |  שם עצם נקבה → מספר ללא ה (שלוש ילדות)

🔗 צורת סמיכות

מתי משתמשים בצורת הסמיכות של המספר?

הכלל:

כאשר שם העצם מיודע (עם ה' הידיעה), נשתמש בצורת הסמיכות של המספר.

✓ שלושת הילדים  (מיודע → סמיכות)
✓ שלושה ילדים  (לא מיודע → נפרד)

⚠ חשוב לזכור:

▸ מעל 10 אין צורות סמיכות: שלושים ושלושה הספרים (ולא: ושלושת)

▸ ת' בסמיכות מופיעה רק בזכר: שלושת הבנים ✓  |  שלוש הבנות ✓ (ולא: שלושת הבנות ✗)

📜 כללי תפס"ת

ארבעה כללים מרכזיים. לחצו על כל כלל כדי לראות דוגמאות:

⬇
ת תאריך – היום בחודש תמיד בזכר
✓ תשעה במאי  |  אחד בחודש (ולא: ראשון, שני)
✗ תשע במאי
⬇
פ אחרי "פי" – המספר תמיד בזכר
✓ פי שלושה
✗ פי שלוש
⬇
ס מספר סתמי – תמיד בנקבה

כשלא סופרים דבר אלא רק מציינים מספר (חדר, עמוד, גיל, ערוץ, תרגיל):

✓ ערוץ אחת (ערוץ מספר אחת)  |  אני בן שלוש עשרה
✗ ערוץ אחד  |  אני בן שלושה עשר
⬇
ת ת' בסמיכות – רק בזכר
✓ שלוש הבנות  |  שלושת הבנים
✗ שלושת הבנות

🔹 שברים

גם בשברים – המין של שם השבר קובע:

הכלל:

בודקים: האם שם השבר הוא זכר או נקבה? לפי זה בוחרים את המונה.

שליש → זכר

לכן: שני שלישים ✓

שמינית → נקבה

לכן: חמש שמיניות ✓

📐 שבר מעורב:

קודם המספר השלם, אחריו שם העצם, ולבסוף השבר:

✓ חמישה פרקים וחצי
✗ חמישה וחצי פרקים

✏ ניקוד אותיות השימוש (וכל"ב)

חמישה כללים לניקוד אותיות השימוש לפני מספרים:

1

הניקוד הרגיל – שווא

שלושים וְחָמֵשׁ

2

לפני שווא → חיריק, ו' בשורוק

שלושים וּשְׁנַיִם  |  כִּשְׁלושה

3

לפני חטף → מקבלים את תנועת החטף

בַּעֲשָׂרָה (חטף פתח → פתח)

4

ו' בשורוק גם לפני ב' ו' מ' פ'

וּמאתיים

5

ו' בקמץ לפני: רבע, חצי

וָחֵצִי

❓ בדקו את עצמכם

3 שאלות קצרות על מה שלמדנו:

1  איזו צורה נכונה? "קניתי ___ עטים"

✅ נכון! עט → עט חדש → זכר. אבל "עט" בזכר → המספר בנקבה (חילופי מינים) = חָמֵשׁ.
❌ לא. עט = זכר → בגלל חילופי מינים המספר יהיה בנקבה: חָמֵשׁ.

2  "ערוץ 1" – איך נהגה?

✅ נכון! מספר סתמי (לא סופרים דבר) → תמיד בנקבה: ערוץ אחת.
❌ זכרו: מספר סתמי (חדר, ערוץ, עמוד) = תמיד נקבה → ערוץ אחת.

3  "שלוש__ הבנות" – מה נוסיף?

✅ מצוין! ת' הסמיכות מופיעה רק בזכר. בנות = נקבה → שלוש (ללא ת').
❌ זכרו: ת' הסמיכות = רק בזכר. "בנות" = נקבה → שלוש הבנות.

❓ עוד קצת תרגול

4  "הטיול בתאריך 9 במאי" – איך?

✅ נכון! תאריך = תמיד בזכר: תשעה במאי.
❌ כלל ה-ת' של תפס"ת: תאריך = תמיד בזכר → תשעה במאי.

5  "המדינה גדולה מישראל פי ___"

✅ נכון! אחרי "פי" = תמיד בזכר: פי שלושה.
❌ כלל ה-פ' של תפס"ת: אחרי "פי" = תמיד זכר → פי שלושה.

6  "___ אלף רקדניות השתתפו בשבוע המחול"

✅ נכון! "אלף" = זכר → המספר שלפני "אלף" בזכר: אחד עשר אלף. (גם אם סופרים רקדניות!)
❌ "אלף" = זכר → המספר שלפניו בזכר: אחד עשר אלף רקדניות.
